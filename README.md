## Features
- **Modern UI/UX:** Clean, cinematic design using deep purples and neon accents.
- **Glassmorphism:** Frosted glass effects on navigation pills and cards.
- **Micro-Interactions:** Smooth 3D tilt effects on project cards, dynamic hover states, and custom cursor tracking.
- **Scroll Spy:** Navigation pill updates dynamically based on scroll position.
- **Fully Responsive:** Beautifully optimized for both desktop and mobile devices.
- **Lighthouse Optimized:** Near-perfect scores in Performance, Accessibility, Best Practices, and SEO.

## Built With
- **HTML5 & CSS3:** Pure, semantic HTML and vanilla CSS without heavy UI frameworks.
- **Vanilla JavaScript:** Fast and lightweight logic for DOM manipulation and animations.
- **Vite:** Next-generation frontend tooling for instantaneous development and optimized production builds.

## Running Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/saubanahmad/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
